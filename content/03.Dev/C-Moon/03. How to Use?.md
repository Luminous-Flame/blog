## CMOON ENV 진입

```
 cmoon 
```

## 데이터 입력  
      
> [!info]
> 기본 적으로 데이터 입력은, cupdate 라는 명령어를 사용하여 대화 형 방식으로 입력합니다.  
> 
> 처음 시작 시, 옵션을 선택하여 작업을 지정 할 수 있습니다.
> - a 옵션 : 전체 데이터 갱신  
> - n 옵션 : 단일 데이터 갱신  
> - d 옵션 : 데이터 삭제  
> - q 옵션 : 업데이트 종료


### 1. 데이터 전체 입력
- 설명 : "a"(All data) 옵션을 사용하여 /var/www/html/cmoon/server_list.csv 를 읽어 전체 데이터를 대조 후 DB에 갱신 또는 입력

- 명령어
```
 cupdate 

Welcome to the cmdb input window!  

Enter option (a: Full data input, n: New server data input, d: Delete data, q: Quit):  a  
```

- 결과 예시
```
a
```
  
### 2. 데이터 단일 입력
- 설명 : "n" (New data) 옵션을 사용하여 단일 데이터를 입력한다. 서버 데이터를 각 항목 별로 입력 받아 입력이 완료 되면 DB에 갱신 또는 입력  

- 명령어
```
 cupdate 

Welcome to the cmdb input window!

Enter option (a: Full data input, n: New server data input, d: Delete data, q: Quit):  n  
```

- 결과 예시
```
a
```

## **데이터 조회**  
      
> [!info]
> 기본 적으로 데이터 조회 시, cview 라는 명령어를 사용  
> - 인자 간 구분은 띄어쓰기를 사용  
> - 하나의 인자에 여러개를 쓸때 ","로 이어 붙이기를 사용  
> - 대/소문자 구분은 하지 않음


### 1. 데이터 전체 조회 
- 설명 : cview 명령어를 인자 없이 입력 할 경우 cmdb의 전체 데이터를 테이블 형식으로 출력합니다.  

- 명령어
```
 cview
```

- 결과 예시
```
a
```
### 2. 호스트 그룹으로 조회
- 설명 : cview + Hostgroup(복수 입력 불가능) 명령어를 입력 시, 입력 된 호스트 그룹에 해당하는 서버들의 전체 정보를 출력합니다.

- 명령어 예
```
 cview hostname
```

- 결과 예시
```
a
```

### 3. 호스트 네임으로 조회    
- 설명 : cview + Hostname(복수 입력 가능) 명령어를 입력 시, 입력 된 호스트(들)에 해당하는 서버 들의 전체 정보를 출력합니다. 

- 명령어 예
```
 cview host-01,hostname-02,host-name-03
```

- 결과 예시
```
a
```

### 4. 호스트 그룹 + 자원 정보를 통한 조회
- 설명 : cview + Hostgroup(복수 입력 불가능) + 자원정보(복수 입력 가능)(대소문자 구분 안함) 명령어를 입력 시, 입력 된 호스트 그룹에 해당하는 서버들의 입력한 자원 정보를 출력합니다.

- 명령어 예  
```
 cview hostname HostName,OS,IP,MAC,CPU,CPUCore,CPUCount,TotalCore,ThreadsPerCore,ThreadsTotal,Memory,Vendor,ProductName,SerialNo
```

- 결과 예시
```
a
```

### 5. 호스트 네임 + 자원 정보를 통한 조회
- 설명 : cview + Hostname(복수 입력 가능) + 자원정보(복수 입력 가능)(대소문자 구분 안함) 명령어를 입력 시,  입력 된 호스트(들)에 해당하는 서버 들의 입력한 자원 정보를 출력합니다.

- 명령어 예
```
 cview host-01,hostname-02,host-name-03 HostName,OS,IP,MAC,CPU,CPUCore,CPUCount,TotalCore,ThreadsPerCore,ThreadsTotal,Memory,Vendor,ProductName,SerialNo
```

- 결과 예시
```
a
```

### 6. 자원 정보 조회 (검색)
- 설명 : cview + 자원정보(복수 입력 가능)(대소문자 구분 안함)(문자열 포함 검색) 명령어를 입력 시,  입력한 자원 정보에 해당하는 서버 들의 전체 자원 정보를 출력합니다.
- 명령어 예	
```
 cview os=ubuntu,cpu=2680,memory=64
```

- 결과 예시  
```
a
```

## **데이터 삭제  

> [!info]
> 데이터 삭제는 데이터 업데이트 명령인 cupdate 를 통해 진행 합니다.  
> 데이터 삭제를 위해서는 Index Value가 필요합니다.  
> Index Value는 cview 에서 특정한 옵션 값으로 확인이 가능합니다.  
> 해당 Index Value 값이 지우려는 Hostname Data와 매칭 되는지 주의하여 삭제 해야합니다.

### 자원 Index Value 검색
- 설명 : 일반 조회로는 보이지 않는 각 서버 별 고유 값인 Index Value를 출력합니다.

- 명령어 예
```
 cview --index
```

- 결과 예시
```
a
```

### 자원 삭제
- 설명 : 위에서 조회 한 Index Value를 통해 데이터 삭제를 진행합니다.

- 명령어 예
        
```
 cupdate

Welcome to the cmdb input window!

Enter option (a: Full data input, n: New server data input, d: Delete data, q: Quit): d
```

- 결과 예시
```
a
```
