# CMOON ENV 진입

- cmoon 은 기본적으로 env 환경 구성으로 세팅되도록 스크립트가 작성 되어있다.
- 따라서 env 환경에 접근하여야 아래의 "명령어"들을 실행 할 수 있다.

``` zsh title="command"
cmoon 
```


---

# 데이터 입력  
      
> [!info]
> 기본 적으로 데이터 입력은, cupdate 라는 "명령어"를 사용하여 대화 형 방식으로 입력한다.  
> 
> 처음 시작 시, 옵션을 선택하여 작업을 지정 할 수 있다.
> - a 옵션 : 전체 데이터 갱신  
> - n 옵션 : 단일 데이터 갱신  
> - d 옵션 : 데이터 삭제  
> - q 옵션 : 업데이트 종료

---  
### 1. 데이터 전체 입력
> [!summary]
> =="a"(All data)== 옵션을 사용하여 /var/www/html/cmoon/server_list.csv 를 읽어 전체 데이터를 대조 후 DB에 갱신 또는 입력

``` zsh title="command"
cupdate 

Welcome to the cmdb input window!  

Enter option (a: Full data input, n: New server data input, d: Delete data, q: Quit):  a  
```

``` zsh title="example"
cupdate a
New data inserted.
New data inserted.
New data inserted.
New data inserted.

...(생략)

New data inserted.

Full data input completed.
```

---  
### 2. 데이터 단일 입력
> [!summary]
> =="n" (New data)== 옵션을 사용하여 단일 데이터를 입력한다.  
> 서버 데이터를 각 항목 별로 입력 받아 입력이 완료 되면 DB에 갱신 또는 입력

# **데이터 조회**  
      
> [!info]
> 기본 적으로 데이터 조회 시, cview 라는 "명령어"를 사용  
> - 인자 간 구분은 띄어쓰기를 사용  
> - 하나의 인자에 여러개를 쓸때 ","로 이어 붙이기를 사용  
> - 대/소문자 구분은 하지 않음
> - ==-t== 옵션 추가 시, 테이블 없이 데이터만 보여짐

---

# 데이터 삭제  

> [!info]
> 데이터 삭제는 데이터 업데이트 명령인 cupdate 를 통해 진행 한다.  
> 데이터 삭제를 위해서는 Index Value가 필요하다.  
> Index Value는 cview 에서 특정한 옵션 값으로 확인이 가능한다.  
> 해당 Index Value 값이 지우려는 Hostname Data와 매칭 되는지 주의하여 삭제 해야한다.

---  
### 자원 Index Value 검색
> [!summary]
> 일반 조회로는 보이지 않는 각 서버 별 고유 값인 Index Value를 출력한다.

``` zsh title="command"
 cview -i
```

``` zsh title="example"
cview -i | grep ed-temp
|      ed-temp-02     | 166767fc8bda665a128570028ab0afee |
```

### 자원 삭제
> [!summary]
> 위에서 조회 한 Index Value를 통해 데이터 삭제를 진행한다.

``` zsh title="command"
cupdate

Welcome to the cmdb input window!

Enter option (a: Full data input, n: New server data input, d: Delete data, q: Quit): d
```
